# CachiBot v2: final views

Open `index.html` for the gallery. `screens/` has a PNG per view, `source/` the HTML each was drawn from.

## Workspace

- `01-workspace`: **Workspace: your bots**. Everything that needs you, then your bots.

## Chat

- `02-chat`: **Chat, bot-first**. One row per bot in the sidebar; the header is just the bot.
- `03-chat-cards`: **Chat cards**. How a turn ends, questions, message actions, background work.

## The bot's computer

- `04-computer-preview`: **Chat + computer preview**. No split view. A small live preview of its desktop sits next to the chat.
- `05-computer-open`: **Computer opened full window**. Mini Vela fills the window; controls live in its top bar; the chat comes along small.
- `06-computer-web-page`: **It built a web page**. Pages the bot builds run on its computer, not in a split preview.
- `07-computer-terminal`: **Claude Code ran**. Coding agents work in its Terminal; the chat gets the diff.
- `08-computer-take-over`: **You take over**. Sign-ins are yours. Yellow ring while you drive; hand back when done.
- `09-computer-off`: **Off / turn on**. First use: what the computer is and where it runs.
- `10-files`: **Files**. Files is its own sheet, separate from the computer.
- `11-mini-vela-spec`: **Mini Vela: what it is**. States of the preview: working, needs you, asleep.

## Runs and setup

- `12-runs`: **Runs**. What your bots ran on their own, by day.
- `13-routine-editor`: **Routine editor**. Routines in plain words.
- `14-bot-settings`: **Bot settings**. One narrow column; rare options under Advanced.
