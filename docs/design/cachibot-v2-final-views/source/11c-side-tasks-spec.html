Side tasks

While a bot works on something, you (or the bot) can hand part of it to a side task: a child chat that works in parallel and reports back. It shows under its parent everywhere, so you always know what belongs to what.

Four ways to start one

On any message: More › Do this on the side
In the composer: + › Side task
Or just say it: “do this on the side”
Or the bot decides: “I started helpers”
What it isA child chat of the main task, run by the same bot. It has its own messages, its own copy of the files, and a short name.
Who starts itYou, when something comes up mid-task. Or the bot, when work splits well (e.g. one helper per Python version). Bot-started ones are called helpers and come as a group.
FilesIts own copy, so it never steps on the main task. In a git repo that's a worktree on a side/… branch; elsewhere, a copy of the folder. Nothing reaches the main task until you bring it in.
ComputerSame computer as the bot. Its windows are labeled with the side task's name, and the preview says how many things are running.
Where it showsIn the chat as a card. In the sidebar nested under the bot, with its status. In Runs under its parent. If it needs you, the parent bot's row says so and it lands in Workspace › Needs you.
EndingDone → Bring into main task, View changes or Discard. The parent chat gets one line saying what came in.
LimitsOne level shown. A side task's own helpers appear as steps inside it, not as more rows. Up to 4 run at once; others wait for a slot. Stopping the main task stops its side tasks.
